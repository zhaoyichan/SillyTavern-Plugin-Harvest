# 📦 一切皆可收纳 · Everything Harvest

一个 **SillyTavern（酒馆）扩展**：把想收藏的聊天记录和桌面上的悬浮球，统一收纳进一个 `＋` 圆球里集中管理，随时回看。

## ✨ 功能

- **收藏聊天记录**：多选聊天楼层（自己/AI 均可、可混选）→ 一键收纳，按角色卡分门别类。
- **收纳桌面悬浮球**：把其它插件的悬浮球（角色日记、内容管家等）收进托盘集中管理，**保持原图标**，点它即打开对应插件。
- **查看收藏**：按角色卡分组浏览，阅读页为**小说排版**，并**原样还原酒馆里的正则美化**（思维链折叠块、图片等）。
- **可拖动小窗 / 全屏**：收藏夹与阅读都支持小窗（真·居中、可拖动）与全屏切换。
- **全局持久化**：收藏与收纳状态跨聊天/跨角色保存，**重启后自动重新收纳**已收纳的悬浮球。
- **内置运行日志**：小窗内实时观测运行情报，方便排查。

## 🚀 安装

在 SillyTavern 的 `extensions/third-party/` 目录下放置本插件文件夹（含 `manifest.json` / `index.js` / `style.css`）：

```
web/extensions/third-party/SillyTavern-Plugin-Harvest/
  ├── manifest.json
  ├── index.js
  └── style.css
```

安装后**完全重启酒馆**即可加载。

> 提示：桌面出现一个可拖动的 `＋` 圆球（日间干爽风）就是插件入口。点它 → 托盘从球心展开。

## 🎮 使用

| 操作 | 说明 |
|------|------|
| 点 `＋` 球 | 展开托盘 |
| 托盘 `＋` 收纳 | 进入"收纳悬浮球"模式，点桌面悬浮球收进托盘 |
| 托盘 `★` 收藏 | 进入多选，点击整条消息选中，点"收纳"收藏 |
| 托盘 `📕` 查看 | 打开收藏夹（按角色卡分组） |
| 托盘 `◯` 日志 | 打开运行日志（可清空/复制） |
| 收藏夹/阅读右上角 | 小窗 ⇄ 全屏 切换 |

- 托盘内点击被收纳的悬浮球 = 打开对应插件界面
- **长按**托盘内被收纳球 / **Shift+点击** = 移出并恢复桌面
